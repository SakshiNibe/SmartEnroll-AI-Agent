# 🤖 SmartEnroll AI Agent

### AI-Based Automatic Student Registration System

SmartEnroll AI Agent is an intelligent student registration system that uses **OCR and AI-based verification** to automatically extract student information from an Aadhaar Card and 10th Marksheet and fill the registration form.

---

## ✨ Features

- 🤖 AI Agent based registration
- 📷 Aadhaar Card OCR
- 📄 10th Marksheet OCR
- ✏️ Automatic form filling
- ✅ Student data verification
- 🔍 Duplicate Aadhaar checking
- 🗄️ MySQL database integration
- 🎉 Registration success confirmation
- 🔐 Uploaded documents are excluded from GitHub using `.gitignore`
